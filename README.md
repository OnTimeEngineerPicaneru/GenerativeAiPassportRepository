# 生成 AI パスポート対策講座 教材

## この講座について

このリポジトリには、**生成 AI パスポート** の合格を目指すプログラミング教室の授業教材が入っています。

生成 AI パスポートは、生成 AI を正しく理解し、安全に・賢く使いこなすための知識を証明する資格試験です。この講座では、AI の仕組みから、AI を使ったプログラミング（バイブコーディング）まで、全 12 回の授業を通して学んでいきます。

## 教材の見つけ方

授業で使うテキストは `Document` フォルダの中にある。

```
Document/
├─ lesson-01/
│   ├─ lesson-01.md        ← 授業で読むテキスト
│   └─ 復習問題-01.md      ← 内容を確認する復習問題
├─ lesson-02/ 〜 lesson-12/  （同じ構成）
```

- **lesson-XX.md**：その回の授業で学ぶ内容がまとまったテキスト。図やたとえ話を使って解説している。
- **復習問題-XX.md**：授業の内容を覚えられているか確認するための問題。穴埋め・選択問題などが入っている。
