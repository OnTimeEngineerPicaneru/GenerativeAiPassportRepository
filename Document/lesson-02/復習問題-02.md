# 復習問題 Lesson-02：AIの基礎知識②

> この問題は Lesson-02「機械学習・ディープラーニング・過学習」の内容を確認するためのものです。

---

## Part 1：穴埋め問題

次の文章の（　）に入る適切な言葉を答えなさい。

1. 人間がルールをプログラムに書き込む方法を（　　　　）という。

2. コンピュータがデータから自分でパターンを学ぶ方法を（　　　　）という。

3. 機械学習の4手法のうち、正解ラベルなしのデータを使う方法を（　　　　）という。

4. 似ているデータ同士をグループに分ける手法を（　　　　）という。

5. 報酬という目標を設定し、最適な行動を学習させる手法を（　　　　）という。

6. 「万能な手法は存在しない」という考え方を（　　　　　　　　）という。

7. 脳の神経細胞の接続部分を（　　　　）といい、AI における情報の重要度を（　　　）という。

8. AI が学習用データに適応しすぎて未知データに対応できなくなる状態を（　　　　）という。

9. 学習中にランダムにニューロンを無効化して過学習を防ぐ手法を（　　　　）という。

10. 一つのタスクで学んだ知識を別のタスクに活用する手法を（　　　　）という。

## Part 2：選択問題

**問1**：「迷惑メールか否かを判定する AI」に最も適した機械学習の手法はどれか。

ア. 教師なし学習  
イ. 強化学習  
ウ. 教師あり学習  
エ. 転移学習  

---

**問2**：ディープラーニングと従来の機械学習の最大の違いはどれか。

ア. ディープラーニングの方が常に精度が高い  
イ. ディープラーニングは特徴量を自動的に学習する  
ウ. ディープラーニングは少ないデータで動く  
エ. ディープラーニングはルールベースの一種である

**問3**：過学習の対策として**含まれないもの**はどれか。

ア. ドロップアウト

エ. クラスタリング

**問4**：次の説明に当てはまる機械学習手法はどれか。「ラベルありデータ（少量）とラベルなしデータ（大量）を組み合わせて学習する」

ア. 教師あり学習  
イ. 教師なし学習  
ウ. 強化学習  
エ. 半教師あり学習

## Part 3：整理問題

次の例を、適切な機械学習の手法（教師あり・教師なし・強化学習）に分類しなさい。

| 例 | 手法 |
|----|------|
| ①メールを「スパム」か「通常」かに分類する | |
| ②ゲームのキャラクターが試行錯誤して最高スコアを目指す | |
| ③大量の顧客データから似た購買傾向のグループを見つける | |
| ④手書き数字の画像に「0〜9」のラベルをつけて学習する | |
| ⑤自動運転車がシミュレーションで正しい運転行動を覚える | |

---

## 解答

### Part 1：穴埋め

1. ルールベース
2. 機械学習
3. 教師なし学習
4. クラスタリング
5. 強化学習
6. ノーフリーランチ定理
7. シナプス、重み
8. 過学習（オーバーフィッティング）
9. ドロップアウト
10. 転移学習

### Part 2：選択

問1：ウ　問2：イ　問3：エ　問4：エ

### Part 3：分類

①教師あり学習　②強化学習　③教師なし学習　④教師あり学習　⑤強化学習
